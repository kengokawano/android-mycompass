マイコンパス プライバシーポリシー

Orange Dev（以下「当社」）は、スマートフォン向けアプリケーション「マイコンパス」（以下「本アプリ」）におけるお客様の情報の取り扱いについて、次のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリは以下の情報を利用します。一部の機能は、事前に利用者の許可を求める場合があります。

  • 位置情報
    端末の GPS / ネットワーク測位により現在地を取得し、コンパスの補正や目的地との距離計算、地図上での現在地表示に利用します。
  • センサー情報
    端末に搭載された磁気センサー・加速度センサー等を利用して方位を算出し、精度ラベルを表示します。
  • 登録した目的地データ
    利用者がアプリ内で登録した地点名称・緯度・経度を端末内に保存し、コンパスや一覧表示に利用します。
  • 地名検索の入力内容
    検索処理に必要な範囲で、利用者が入力した検索語句を外部ジオコーディングサービス（OpenStreetMap Nominatim）へ送信します。

2. 情報の利用目的

取得した情報は、以下の目的でのみ利用します。

  • コンパス表示、目的地までの方角・距離計算
  • 地図上での地点表示および検索機能の提供
  • 登録した目的地の保存・編集・削除機能の提供
  • アプリの機能改善・品質向上に必要な範囲での解析（個人を特定しない統計的な情報に限ります）

3. 情報の保存と共有

  • 端末内保存
    登録地点などの設定データは端末内に保存され、当社サーバーへ送信されることはありません。
  • 第三者提供
    法令に基づく場合を除き、利用者の許可なく第三者へ個人情報を提供することはありません。

4. 外部サービスの利用

本アプリは地名検索のために、OpenStreetMap プロジェクトが提供する Nominatim API（https://nominatim.org/）を利用します。検索語句と端末から要求された位置情報が、同サービスのサーバーに送信される場合があります。送信先サービスの利用規約およびプライバシーポリシーをご確認ください。

本アプリの地図データは © OpenStreetMap contributors の提供するライセンス（ODbL）に基づき利用しています。

5. アクセス権限について

本アプリは以下の権限を要求する場合があります。

  • 位置情報（精密 / おおまかな位置）: 現在地の取得、および目的地との距離計測に必要です。
  • センサー（コンパス、加速度計）: 方位と傾きの計算に使用します。

権限は端末の設定画面からいつでも変更できます。なお、権限を無効にすると一部機能が利用できなくなる場合があります。

6. セキュリティ

当社は、取得した情報が漏えい・改ざん・不正アクセス等されないよう、合理的な安全対策を講じます。

7. プライバシーポリシーの変更

本ポリシーの内容は、法令の改正やサービスの変更に応じて、予告なく変更する場合があります。変更後は、本ページに速やかに掲載します。
